# Explicación

App mínima de Streamlit que muestra la palabra **Explicación** centrada en la pantalla.

## Correr local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Desplegar

1. Entra a https://share.streamlit.io
2. "Create app" → elige este repo, branch `main` y archivo `app.py`
3. La URL queda como `https://<nombre-que-elijas>.streamlit.app`
